1. An enterprise wants to prevent individual orgs from disabling required PR reviews. What should they configure?
A.	Org-level branch protection
B.	An enterprise policy
C.	A CODEOWNERS file
D.	A workflow requirement

Answer: B
Explanation: Enterprise policies override org-level settings. Setting this at the enterprise level prevents orgs from weakening the requirement.


2. An admin needs to send logs to GitHub Support for a GHES outage. What should they generate?
A. 	GraphQL report
B.	A support bundle
C.	An audit log export
D.	A webhook payload

Answer: B
Explanation: A support bundle packages all relevant logs and diagnostics from a GHES instance in a format GitHub Support an analyze


3. Your self-hosted runner is inside a private network. Actions jobs are failing because github.com is blocked. What should you configure?
A.	IP allow list on GitHub
B.	A proxy for the runner
C.	A GitHub-hosted runner
D.	A runner group

Answer: B
Explanation: Self-hosted runners in restricted networks must be configured with a proxy so they can reach GitHub.com to receive job assignments and download Actions


4. Your company uses Okta. You want GitHub accounts auto-deprovisioned when employees leave. What should you configure?
A.	SAML SSO only
B.	Team Synchronization
C.	SCIM provisioning
D.	2FA enforcement

Answer: C
Explanation: SCIM automates user lifecycle management — it provisions new accounts and deprovisions them when users are removed from the IdP, like Okta.


5. What is the key difference between Team Synchronization and SCIM?
A.	Team Sync provisions/deprovisions GitHub accounts; SCIM manages team membership
B.	SCIM provisions/deprovisions accounts; Team Sync manages IdP group-to-team mapping
C.	They are identical features
D.	Team Sync only works with Azure AD

Answer: B
Explanation: SCIM manages the user account lifecycle (create/delete). Team Sync maps IdP group memberships to GitHub teams — both can work together for full identity management.


6. A Windows runner uses how many GitHub Actions minutes per actual minute of compute?
A.	1×
B.	2×
C.	5×
D.	10×

Answer: B
Explanation: Windows runners are billed at 2× the rate of Linux runners. macOS runners are billed at 10×. Linux is the 1× baseline.



7. A team wants to publish their npm package so other internal teams can consume it in their Actions workflows. What should they use?
A. 	GitHub Releases
B.	GitHub Gists
C.	GitHub Packages
D.	A public npm registry

Answer: C
Explanation: GitHub Packages provides an internal npm registry that integrates with GitHub authentication — ideal for sharing private packages across internal teams.


8. A developer accidentally committed an AWS secret key. It's already pushed. What is the FIRST step?
A.	Delete the repo
B.	Revoke the secret in AWS immediately
C.	Run git filter-branch
D.	Contact GitHub support

Answer: B
Explanation: The secret is already exposed — revoking it in AWS is the most urgent step to stop potential misuse. Then clean the history and rotate credentials.


9. Which GitHub feature automatically opens PRs to fix packages with known CVEs?
A.	Secret scanning
B.	Code scanning
C.	Dependabot security updates
D.	GitHub Advisory Database

Answer: C
Explanation: Dependabot security updates automatically create pull requests to bump vulnerable dependencies to safe versions based on the GitHub Advisory Database.
