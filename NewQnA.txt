1. An IT development team is configuring branch protection in a GitHub repository. They enable multiple rulesets that apply to the same branch. What outcome should the team expect?

9. When an enterprise enables and enforces SCIM (System for Cross-domain Identity Management) provisioning with its Identity Provider (IdP), what is the primary benefit regarding user accounts on GitHub?
A.	Users can access GitHub resources without ever needing to sign-in
B.	It automatically enables two-factor authentication (2FA) for all users
C.	It automates the creation, updating, and deactivation of user accounts on GitHub based on changes in the IdP
D.	It prevents the user of Personal Access Tokens (PATs) entirely

Answer: C
Explanation: CSIM synchronizes account creation, updates and deactivation automatically, ensuring accurate access control. This reduces administrative work and strengthens overall security management.
